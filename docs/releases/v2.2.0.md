# v2.2.0

Stable release of **Pterodactyl Minecraft Multi-Profile Manager** after real Pterodactyl environment testing.

## Highlights

- Unicode/Korean profile names
- `profile.conf` automatic creation
- Better imported-server detection using `logs/latest.log`, `versions/`, jar names, and common layouts
- Automatic Java 8 / 11 / 16 / 17 / 21 / 25 selection and caching
- Correct `SERVER_MEMORY=0` / Pterodactyl Unlimited behavior
- Primary Allocation port enforcement
- Automatic backup of the previously active profile on switch
- `BACKUP_KEEP` retention verified in a real environment
- Invalid/missing profile rejection
- Pterodactyl `Launch SFTP` + WinSCP documented as the recommended large-file workflow
- Experimental dynamic Startup dropdown / Panel patch removed

## Real environment verification

The release was tested for clean startup, Korean profile names, Paper 1.21.11 with Java 21, Paper 26.2 with Java 25, automatic Java switching, profile backups, backup retention, missing-profile rejection, actual Minecraft client connections, and profile round-trips with world persistence.

## AI assistance

OpenAI ChatGPT was used during design, implementation, debugging, documentation, and release preparation. Final feature choices, real-environment testing, distribution, and repository management remain with the repository owner.
