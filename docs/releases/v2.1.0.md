# v2.1.0

First public release of **Pterodactyl Minecraft Multi-Profile Manager**.

## Highlights

- Run multiple independent Minecraft server folders from one Pterodactyl server and one primary allocation.
- Switch profiles with `SERVER_PROFILE`.
- Automatically create `profile.conf` when missing.
- Detect common server layouts including Paper, Purpur, Folia, Spigot, Vanilla, Fabric, Quilt, Forge, NeoForge, Mohist, Magma, and Arclight.
- Detect Minecraft versions where possible.
- Automatically select and cache Java runtimes for Java 8, 11, 16, 17, 21, and 25.
- Apply per-profile configuration overrides.
- Refuse unsafe or ambiguous profile launches instead of guessing.
- Back up the previously active profile when switching.
- Force the selected profile to use the current Pterodactyl primary allocation.
- Optional dynamic `SERVER_PROFILE` dropdown for the Pterodactyl Startup page by scanning `/servers`.

## Included

- `egg/egg-minecraft-multi-profile-manager-v2.1.json`
- Dynamic Startup dropdown Panel patch
- Install / uninstall scripts for the Panel patch
- Migration notes from v1 to v2
- MIT License

## Important notes

- Only one profile is intended to run at a time.
- The dynamic dropdown modifies the Pterodactyl Panel frontend and may need to be re-applied after Panel updates.
- Profile backups are filesystem `.tar.gz` archives and are separate from Pterodactyl's built-in Backups tab.
- Always keep independent backups of important Minecraft worlds.
