# Contributing

Contributions are welcome.

## Bug reports

Please include:

- Pterodactyl Panel version
- Wings version when relevant
- Minecraft version
- Server implementation (Paper, Forge, Fabric, etc.)
- The affected `profile.conf` with secrets removed
- Relevant launcher console output

## Pull requests

Keep changes focused and avoid unrelated formatting changes. For auto-detection changes, prefer safe failure over guessing when multiple candidates are possible.

## Security and privacy

Never include API keys, server tokens, passwords, world data, player data, or private configuration in issues or pull requests.
