# AI Assistance Disclosure

This project was developed with substantial assistance from **OpenAI's ChatGPT**.

ChatGPT was used throughout the project for tasks including:

- discussing the overall architecture and implementation approach;
- generating and refactoring code;
- troubleshooting Pterodactyl Egg and Panel integration issues;
- designing the multi-profile, automatic Java selection, backup, and dynamic dropdown behavior;
- writing and revising documentation;
- preparing release notes and release assets.

The project goals, feature decisions, real-world testing, repository management, and publication are handled by the repository owner. AI-generated code and suggestions may contain mistakes, so users should review and test the project in their own environment before relying on it in production.

This disclosure is included to make the project's development process transparent to contributors and users.
